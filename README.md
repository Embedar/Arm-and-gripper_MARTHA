# Brazo Robótico MARTHA — Fork de desarrollo

Este repositorio es un **fork** del proyecto original, creado con el objetivo de
gestionar y documentar los avances del **brazo robótico del robot MARTHA**.

## 🎯 Propósito

Centralizar en un espacio propio:
- Los avances en el diseño mecánico del brazo.
- El desarrollo y las pruebas de software de control.
- La integración de sensores y actuadores.
- La documentación técnica y los registros de pruebas.

## 🌿 Ramas de trabajo

| Rama | Descripción |
|------|-------------|
| `main` | Versión estable sincronizada con el repositorio original |
| `dev-brazo` | Desarrollo activo del brazo robótico |
| `pruebas` | Pruebas de laboratorio y calibración |
